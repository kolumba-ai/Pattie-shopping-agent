# Personal Agent Tenets

Personal Agents Hackathon, San Francisco, November 20, 2026

1. **Ownership.** The owner of the personal agent keeps control and ownership of their data.

2. **Security and convenience.** The provider takes care of software patches and updates, so the owner doesn't have to.

3. **Mobile.** The agent is built for mobile and works from the owner's phone.

4. **Proactive.** The agent acts on its own when something happens: an event on the owner's calendar, or a message in the WhatsApp text box.

5. **Cost effective.** The agent runs on an open model to keep costs low.

6. **Traceable.** Every action the agent takes can be traced, using Amplitude and Statsig.

7. **Remembers.** The agent keeps a memory of the owner across conversations, using Cognee.
